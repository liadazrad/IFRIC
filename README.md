# מעקב החלטות ודיוני IFRS

אתר מחקר ומעקב ממוקד `IFRIC / IFRS`, עם דגש על:

- נושאים חדשים שעלו לאחרונה
- פגישות IFRIC וניירות עבודה לפי `AP`
- החלטות סדר יום סופיות עם חיפוש גם בתוך הטקסט המלא
- קישור בין החלטות סופיות לבין ניירות עבודה שקדמו להן
- נושאים פתוחים, מעקב אחרי סטטוס, וסימון פריטים שדורשים בדיקה ידנית

## הרצה מקומית

ב־Windows:

- לחץ פעמיים על `launch-site.bat` והשאר את החלון פתוח.

או דרך PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-site.ps1
```

ואז פתח:

```text
http://localhost:8081
```

## קבצים מרכזיים

- `index.html` - מבנה האתר והלשוניות
- `styles.css` - העיצוב
- `app.js` - לוגיקת הטעינה, חיפוש, סינון ומודאל פריט
- `data/ifric.json` כולל רשומות מהקטלוג האנגלי הרשמי, טקסט לחיפוש וניירות עבודה שקושרו.
- `data/ifric-paper-overrides.json` שומר התאמות שנבדקו, למשל כשכותרת הנושא השתנתה או שכמה החלטות פורסמו תחת אותו סעיף בסדר היום.
- `data/ifrs-monitor.json` כולל סדרי יום, פרויקטים פעילים ושינויים שנמצאו בסנכרון.
- `data/ifrs-editorial.json` ו־`data/ifric-titles-he.json` שומרים ניסוחים שנערכו מול המקור.
- `scripts/sync-ifrs.py` קורא את המקורות ומעדכן את הנתונים. `scripts/translate_ifrs.py` מתרגם טקסט חדש או שהשתנה בעזרת מודל מקומי.

## עדכון נתונים ידני

לשיוך ניירות עבודה מחדש מהנתונים שכבר שמורים, ללא גישה לאינטרנט או לחשבון IFRS:

```powershell
python -B scripts/sync-ifrs.py --backfill-papers
```

## סנכרון מקורות

יש להשתמש בסנכרון המקורות רק לאחר קבלת הרשאה מתאימה מ־IFRS Foundation.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-datasets.ps1
```

## עדכון אוטומטי

בפרויקט קיימת פעולה מתוזמנת מדי יום בקובץ `.github/workflows/update-data.yml`. כשהיא מוגדרת ופועלת בהצלחה, החלטות חדשות נכנסות לארכיון, נושאים וניירות חדשים מופיעים ב״על הפרק״, ושינויים מופיעים ב״מה חדש״. תרגום מקומי אינו דורש מפתח API.

[תנאי IFRS Foundation](https://www.ifrs.org/legal/terms-and-conditions/) מגבילים איסוף ואינדוקס אוטומטיים. [רישוי IFRS](https://www.ifrs.org/products-and-services/ifrs-accounting-licensing/) מציע עדכוני תקנים והטמעה למורשים, אך צריך לברר אם הרישיון מכסה גם החלטות IFRIC, סדרי יום, ניירות עבודה ותרגום. [התראות הדוא״ל הרשמיות](https://www.ifrs.org/dashboard/) זמינות למעקב אישי ואינן הזנת נתונים לאתר.

## הערה חשובה

קטלוג ההחלטות כולל את רשימת `All agenda decisions` באנגלית והחלטות סופיות נוספות שזוהו בעדכוני IFRIC הפומביים בפורמט HTML. עדכוני עבר הזמינים רק ב־PDF אינם מפוענחים כהחלטות נפרדות. ניירות עבודה משויכים כשנמצא בסיס להתאמה. תקצירים שתורגמו אוטומטית מסומנים בממשק, והמקור הרשמי זמין בכל פריט.
